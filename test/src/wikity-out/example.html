TextFunctions

Each side of the = must match.
  • text = text
  • Text = Text
  • 5 = 5
  • trin = ring
  • 2 = 2
  • _text = _text
  • msg__ = msg__
  • M3ssag3 = M3ssag3
  • C = C
  • t%20e%20x%20t = t%20e%20x%20t
  • a b'c = a b'c

ParserFunctions

Each side of the → must match.
  • true text → true text
  • false text → false text
  • None = None
  • Image:
= [Example.png]
  • → (empty: variable defined)
  • value → value
  • "this = unset" → "this = unset"
  • one → one
  • 2021-03-27 (Sat) m → [today's date] m
  • → (empty: variable defined)
  • nil =. → nil =.
